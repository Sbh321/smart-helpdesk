# Internship report sources

A basic template with drafted generic prose. Fill every `<<field>>` in `metadata.json` and the chapter files, add `figures/org-chart.png`, then build with `npm run build:internship` from `report/`. The structure follows the common TU BCA internship format (introduction; organisation details and literature review; internship activities; conclusion and learning outcomes). Check it against your department's internship guideline and adjust headings if they differ.
