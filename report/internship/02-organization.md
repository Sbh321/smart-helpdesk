## 2.5 Literature Review

Modern web applications are commonly built as a backend API and a separate single-page frontend. Laravel provides routing, an object-relational mapper, queues, scheduling and mail for PHP applications [@laravel13]. React builds user interfaces from components [@react], and the TanStack libraries manage routing, server data, tables and forms [@tanstack]. PostgreSQL is a relational database with strong support for constraints, full-text search and row-level security [@postgres]. Docker packages applications with their dependencies so that the same image runs on a developer machine and a server [@docker]. Teams coordinate changes with Git [@git] and commonly follow iterative, agile practices [@beck; @sommerville]. Secure development is guided by the OWASP Top 10 [@owasp].
