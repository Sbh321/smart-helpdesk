# Database overview

PostgreSQL 18 is the only database ([ADR-0005](../adr/0005-postgresql.md)); UUID v7 keys ([ADR-0013](../adr/0013-identifiers.md)); shared schema with `tenant_id` and RLS ([ADR-0006](../adr/0006-multi-tenancy-model.md)). Data principles: [03-architecture/data.md](../03-architecture/data.md). Tables: [entities.md](entities.md). Indexes: [indexing.md](indexing.md). Tenancy at the DB level: [tenancy.md](tenancy.md). Migrations: [migrations.md](migrations.md).

## Roles

| Role | Used by | Rights |
|---|---|---|
| `helpdesk_owner` | migrations, seeders, `Platform` provisioning connection (`pgsql_owner`) | owns all objects; DDL; bypasses RLS only where policies are not `FORCE`d (they all are) |
| `helpdesk_app` | `app`, `horizon`, `scheduler`, `reverb` | `SELECT, INSERT, UPDATE, DELETE` on application tables; `SELECT, INSERT` only on `audit_logs`, `ticket_events`, `sla_events`; `USAGE` on the schema; **no** ownership, `NOBYPASSRLS`, `NOSUPERUSER` |
| `postgres` | container bootstrap only | superuser; never referenced by the application |

Connection config: `DB_USERNAME=helpdesk_app` by default; a second connection `pgsql_owner` with `DB_OWNER_USERNAME` is used by `migrate` and by `ProvisionTenant`.

## Extensions

| Extension | Purpose | Required |
|---|---|---|
| `pg_trgm` | trigram indexes for typeahead, `ILIKE`, duplicate candidate pre-filter | yes |
| `btree_gin` | optional composite `(tenant_id, search_vector)` GIN if measurements show bitmap-AND is too slow | no (V1) |
| `pgvector` | semantic search | no (V1) |

UUIDs are generated by the application (`HasUuids` → UUID v7); PostgreSQL 18's `uuidv7()` is used only in seed SQL and experiments. No `pgcrypto`.

## Naming conventions

| Object | Convention | Example |
|---|---|---|
| Tables | `snake_case`, plural | `ticket_sla_timers` |
| Pivot tables | singular_singular alphabetical (Laravel default) or descriptive plural | `category_skill`, `team_members` |
| Primary key | `id uuid` | |
| Foreign keys | `<singular>_id` | `assigned_agent_id` |
| Timestamps | `<verb>_at timestamptz` | `resolved_at` |
| Booleans | `is_<adj>` / `has_<noun>` | `is_active` |
| Counters | `<noun>_count` | `active_ticket_count` |
| Indexes | `<table>_<cols>_idx`, unique `<table>_<cols>_key`, partial `<table>_<purpose>_pidx` | `tickets_tenant_status_priority_idx` |
| Check constraints | `<table>_<col>_check` | `tickets_status_check` |
| RLS policies | `tenant_isolation` on every tenant table | |

## Column type rules

| Kind | Type |
|---|---|
| Identifiers | `uuid` |
| Enumerations | `varchar(32)` + `CHECK (col IN (...))`; never PostgreSQL `ENUM` types (painful to alter) |
| Timestamps | `timestamptz`, always UTC; no `timestamp without time zone` |
| Money | none |
| Text | `varchar(n)` for bounded fields (title 200, name 120, email 254), `text` for bodies |
| Numbers | `smallint` for 1–4 scales, `integer` counters, `numeric(5,2)` for `priority_score`, `numeric(6,4)` for similarity scores |
| JSON | `jsonb` only; schema validated in PHP; size limits enforced by validation (8 KB metadata, 64 KB explanations) |
| Full text | `tsvector GENERATED ALWAYS AS (...) STORED` |
| Arrays | `text[]` for webhook `events`; otherwise normalised tables |

## Soft deletes

Only `contacts.archived_at` and `tenants.archived_at` (soft); everything else is either kept forever (tickets, history, audit), hard-deleted with `RESTRICT` guards (categories, skills, teams, tags, SLA policies when unused), or pruned by retention commands (webhook deliveries 30 d, read notifications 90 d, pending attachments 1 h, idempotency keys 24 h).

## Size targets

| Metric | MVP tested | Architectural target |
|---|---|---|
| Tickets per tenant | 100 000 | 1 000 000 (partitioned history) |
| Tenants | 20 | thousands (shared) + dedicated placements |
| Rows in `ticket_events` | 1 000 000 | partition by month |
| Concurrent app connections | ≤ 40 (FPM 20 + Horizon 12 + scheduler + Reverb) | pooler with `SET LOCAL` design |
| Database size | < 5 GB | — |

`max_connections=100`, `shared_buffers=25 %` of RAM, `work_mem=16MB` in the Compose PostgreSQL config for the reference VM.
