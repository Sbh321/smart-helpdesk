# Report chapter mapping

Where each section of the CACS452 report ([university-requirements.md](university-requirements.md)) gets its content. **The report and the platform documentation are different documents**: `docs/` is the engineering documentation of the product (present tense, for developers and operators); `report/university/` is the academic narrative (past tense, contextualised, IEEE-cited) that draws on `docs/` but never copies it verbatim. Rules and pipeline: [report-generation.md](report-generation.md).

## Front matter

| Part | Source |
|---|---|
| Cover, title, certificate, approval letters | templates in `report/university/front-matter/` filled with names/dates (owner input) |
| Acknowledgement | owner |
| Abstract (≈ 250 words) | vision + goals + headline results (written last) |
| Lists of abbreviations, figures, tables | generated by the pipeline from captions and an abbreviations file |
