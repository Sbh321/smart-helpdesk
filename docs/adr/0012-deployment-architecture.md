# ADR-0012 Deployment: Docker Compose everywhere, Caddy edge, OpenTofu + Ansible for one VM

**Status:** Accepted (2026-09-17); reference-cloud clause superseded by [ADR-0017](0017-cloud-agnostic-deployment.md); per-tenant TLS superseded by [ADR-0021](0021-host-layout-and-tenant-resolution.md)

## Context

Targets: developer workstation, single-server on-prem, single cloud VM; the same images everywhere; Terraform and Ansible must exist but stay minimal. Research: [01-research/deployment-options.md](../01-research/deployment-options.md).

## Decision

- **Images**: backend on `serversideup/php:8.5-fpm-nginx` (one image for `app`, `horizon`, `scheduler`, `reverb` with different commands; built-in healthcheck, PUID/PGID, S6 signal handling) plus `pdo_pgsql`, `redis`, `uv`, `intl`, `gd`, `bcmath`, `pcntl`, `postgresql-client`; frontend built by a multi-stage Node 24 stage into a static bundle served by the edge proxy (runtime config injected as `/config.json`, not baked `VITE_*`).
- **Compose**: root `compose.yaml` with `include` of `infra/compose/{base,dev,prod}.yaml` and profiles (`dev`, `demo`, `storage`, `realtime`): services `proxy` (Caddy), `app`, `horizon`, `scheduler`, `reverb` (profile), `postgres`, `valkey`, `rustfs` (profile), `mailpit` (dev), `webhook-echo` (demo). Healthchecks with `depends_on: condition: service_healthy`; named volumes; secrets via env file generated by Ansible (Compose `secrets` for DB password).
- **Edge**: **Caddy 2** with automatic HTTPS: on-demand TLS with an `ask` endpoint for tenant subdomains in SaaS, internal CA or customer certificate on-prem, `tls internal` for `*.helpdesk.localhost` in dev. Serves the SPA, proxies `/api`, `/docs`, `/horizon`, `/app` (websocket), `/apps`.
- **Cloud IaC**: **OpenTofu 1.12** (MPL) with provider-neutral module contracts (`network`, `firewall`, `compute`, `storage`, `dns`) and **DigitalOcean** as the first reference provider (all five resources native), Hetzner documented as the second; state encrypted locally. Under 200 lines. Output feeds the Ansible inventory.
- **Host configuration**: **Ansible** (ansible-core 2.21) roles `common`, `docker` (`geerlingguy.docker`), `app` (env, compose up, migrate, seed), `proxy`, `backup`, `firewall` (ufw). Nothing but Docker is installed on the host.
- **Backups**: `spatie/laravel-backup` to the S3 disk (database + attachments) plus a host `pg_dump` systemd timer as a dumb safety net; restore rehearsed in milestone 3.
- **Logs**: JSON to stdout, Docker `json-file` driver with rotation; **no** OpenTelemetry in the MVP.

## Alternatives considered

FrankenPHP/Octane (stateful workers vs tenant context; rejected for MVP), hand-rolled `php:8.5-fpm-alpine` (more Dockerfile to own), nginx/Traefik edge (no automatic internal CA), Terraform (BUSL, IBM licensor), AWS first (most boilerplate, highest cost), Hetzner first (no native bucket resource), Kubernetes (out of scope), SOPS/age secrets (team problem we do not have).

## Consequences

Same images from laptop to cloud; on-prem needs one VM with Docker; subdomain TLS handled by Caddy; cloud cost ≈ $30/month for the reference stack.

## Migration / future considerations

Managed PostgreSQL and object storage in cloud; multiple app replicas behind the proxy with Reverb scaling; Kubernetes only past that; GitOps secrets when a second operator joins.
