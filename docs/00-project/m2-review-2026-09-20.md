## Backend

### Cross-cutting
- [x] **Module cycles (rework of the wiring).** Tickets imports Automation and Sla; Agents imports Automation and Tickets. Design: `Tickets → Contacts, Agents, Media`; `Automation → Tickets, Agents, Sla`; `Sla → Tickets`. Fix: synchronous in-transaction hook events in Tickets (`TicketCreated`, `TicketInputsChanged`, `FirstPublicReplyRecorded`); Automation and Sla listen. Move duplicate orchestration, `AgentDirectory::forTicket`, `AgentWorkload`, the workload listener and `agents:reconcile-workload` into Automation. Tighten `tests/Architecture/ModulesTest.php`.
- [x] Composite foreign keys with plain `SET NULL` null `tenant_id` too and fail: `contacts.organization_id` (M1), `ticket_duplicate_suggestions.decided_by_user_id`, `media_items.folder_id`, `media_items.uploaded_by_user_id`. Use `ON DELETE SET NULL (column)`.
- [x] Stable 409/422 codes instead of bare `abort(409)`: `already_assigned`, `in_use`, `already_decided`, `resolution_comment_required`, `sla_target_missing`; `no_eligible_agent` on `/auto-assign`.
- [x] Stale tests: `CreateTicketTest`, `TicketLifecycleApiTest` (5), `TicketSlaLifecycleTest` (4), `MediableFactory`.

### M2-10 Duplicates
- [x] Depth-2 chain possible: marking A as duplicate when A already has duplicates.

- [x] Backend tests added (`tests/Feature/Automation/DuplicateApiTest.php`).

### M2-08 Media (**rework `CompleteUpload`**)
- [x] Disk names hard-coded (`s3`, `s3-presign`), so nothing runs under the test environment. Add `MediaStorage`.
- [x] Presigned PUT replayable after verification: upload goes to a staging key (`uploads/`) and is moved to `media/{id}/original` on complete. SigV4 presigning leaves `Content-Length` unsigned, so completion re-checks the real size (live check: 5 000 bytes against a declared 10 answers 422).
- [x] `complete` holds the ticket-number row lock during S3 I/O; reads the whole object into memory twice; `get()` null → TypeError.
- [x] MIME matching rejects real DOCX and Windows ZIP; config values unused.
- [x] Variants job: no pixel cap, decodes twice, wrong queue.
- [x] `MediaItemResource` N+1 (about 5 queries per item).
- [x] Download ignores the linked-ticket policy; rename not sanitised before `Content-Disposition`.
- [x] No throttle on intent; index does not extend `ListRequest`; `MediaTags` duplicates `HasTags` in raw SQL.
- [x] Tests: 286 under `tests/Feature/Media` and `tests/Unit/Media`. They found two bugs, both fixed: a false `media.quota.clamped` warning on every release, and a dotfile download name for names without an ASCII form.
