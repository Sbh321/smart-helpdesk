# Milestone 4 — UX redesign

**Milestone status:** `[x]` Done — 14 of 14 tasks done (2026-09-24). The AWS redeploy of the redesigned SPA is the one step left open in M4-14, waiting for the owner's go-ahead.

Goal: raise the interface from "functionally complete" to an operational product an agent can work in all day, on top of the design system that already exists. The audit that motivates every task is [docs/06-design-system/ux-review.md](../docs/06-design-system/ux-review.md); its findings are referenced as G1–G8.

Not a rebuild: tokens, primitives, themes and the accessibility gates stay as they are ([ux-review §What the audit found healthy](../docs/06-design-system/ux-review.md#what-the-audit-found-healthy)). Storybook is deliberately not adopted (G1). Mobile below 768 px stays V1.

## Order

One task at a time, in this order. Each keeps the application working, the test suites green and the axe scans at zero.

```text
foundations   M4-01 → M4-02 → M4-03
operations    M4-04 → M4-05 → M4-06 → M4-07
analysis      M4-08 → M4-09
platform      M4-10 → M4-11
sweep         M4-12 → M4-13 → M4-14
```

## Definition of done for a redesigned screen

Beyond the general [definition of done](../docs/10-quality/definition-of-done.md): hierarchy is deliberate (primary information readable without hovering or clicking); no raw identifier or storage value is shown where a name exists; loading, empty, no-results, error and forbidden states all render; keyboard order matches visual order; light and dark checked; axe clean; browser and E2E selectors updated in the same task; the pattern is written into [page-patterns.md](../docs/06-design-system/page-patterns.md) if another screen will copy it.
